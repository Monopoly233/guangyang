> 单一功能、无注册、付费即用。

🌐 https://www.guangyang.online/

---

## 它是什么

一个极简 SaaS 工具，只做一件事：**比对两份表格，输出差异**。

- 上传两份 Excel/CSV
- 自动识别新增的行、删除的行、变更的字段
- 微信支付按次/按月付费即用
- **不需要注册、不存储任何用户数据**

为会计需求而做，但任何需要做表格对账的财务、行政、运营都能用。

## 为什么没有用户系统

最初的版本有完整的用户注册和鉴权流程。开发到一半意识到：

1. 用户系统的复杂度（鉴权、密码找回、邮箱验证、隐私合规）远大于核心功能本身
2. 财务数据敏感，不存用户数据反而是优势
3. 一个工具型产品，付费即用比注册更顺

砍掉了整个用户模块。

## 工程决策

**从多节点 K8s 缩到单机**
原 K8s 集群月成本 ¥2000 (年 ¥24000)，对一个早期 SaaS 工具不可持续。缩到单机 ¥1500/年，可用性下降但成本降到 1/16。在产品验证阶段是正确的权衡。

**砍掉用户系统**
见上文"为什么没有用户系统"。

**自建 GitLab + ARC**
完整控制构建环境，不依赖公共 CI 服务，避免供应商锁定。
